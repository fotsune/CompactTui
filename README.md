# CompactTui

Консольный сжиматель папок для Windows. Отмечаете папки в меню, программа сжимает их
штатной утилитой `compact` (NTFS, алгоритм LZX) и показывает, сколько места освободилось.
Файлы остаются на месте и остаются обычными файлами — меньше занимают только их данные
на диске. Разжать обратно можно тем же `compact /U` или открыв файл в проводнике.

```
+----------------------------------------------------------------+
|                          [d:/games]                            |
|                        Выберите папки                          |
|                                                                |
|   [x] alpha[1.2k|13.2g]    [ ] beta[300|4.0m]                 |
|   [x] tmp[9|12.0k]                                             |
|                                                                |
|   {Пробел для выбора, Enter для подтверждения}                 |
|   {'A' для выбора/отмены всех, Shift+Q Выход}                  |
|   ['F' Сжать принудительно: False] ['D' Режим HDD: False]      |
|   {[файлов|на диске]} зелёная — сжата · оранжевая — не дожата  |
+----------------------------------------------------------------+
```

## Быстрый старт

1. Положить `CompactTui.exe` в любую папку и запустить. Права администратора
   программа запросит сама: без них `compact` не прочитает чужие файлы.
2. Ввести путь к папке (или сразу запустить с `-p D:\games`), отметить нужные
   подпапки `Пробелом`, нажать `Enter` и подтвердить ещё раз `Enter`.
3. Дождаться итога: «Готово: сжато 3 из 3, освобождено 0.033 ГиБ, ошибок 0,
   прошло 6 с». `Enter` возвращает к выбору папок — уже с новыми размерами.

Нужны Windows 10/11 и файловая система NTFS: на FAT32 и exFAT `compact` ничего
не сжимает.

## Флаги

| Флаг | Что делает |
| --- | --- |
| `-p <путь>` | папка, подпапки которой попадут в меню; `-p` без значения — сразу спросить путь |
| `-a` | отметить все папки сразу |
| `-z` | показывать полные пути, а не только имена |
| `-f` | сжимать принудительно, включая уже сжатые файлы (ключ `/F`) |
| `-hdd` | по одной папке за раз: медленнее на SSD, зато предсказуемее на HDD |
| `-n`, `-nosize` | не считать размеры и число файлов — меню открывается сразу |
| `-l` | не показывать логотип при старте |
| `-h`, `-help` | справка и выход |

```bat
CompactTui.exe                                :: спросит путь и покажет меню
CompactTui.exe -p D:\games -a -hdd           :: все папки D:\games, по одной
CompactTui.exe -p "C:\Program Files\Logs" -a -z -f
CompactTui.exe -h
```

Неизвестные флаги игнорируются.

## Клавиши

| Где | Клавиши |
| --- | --- |
| меню | стрелки — по сетке, `Пробел`/`X` — отметить, `A` — все/ничего, `Enter` — подтвердить, `F` — принудительно, `D` — режим HDD, `Shift+G` — стереть историю, `Q`/`Esc` — выход |
| ввод пути | `←` `→` — по строке, `Home`/`End`, `Backspace`/`Delete`, `Ctrl+U`/`Ctrl+K` — стереть слева/справа, `Enter` — принять, `Esc` — выход |
| сжатие | `Esc` — перестать ждать (сам `compact` доведёт папку до конца), `Enter` после итога — назад к выбору папок |

Русская раскладка работает: `X`/`Ч`, `A`/`Ф`, `F`/`А`, `D`/`В`, `Q`/`Й`.

## Подписи и цвета

`alpha[1.2k|13.2g]` — 1200 файлов, 13.2 ГиБ **на диске**. Именно на диске: при
NTFS-сжатии логический размер файлов не меняется, место занимают сжатые данные.

- **зелёная** — папка уже сжата: программа сжимала её раньше или на диске она
  заметно меньше, чем её файлы (то есть сжали мимо программы);
- **оранжевая** — папка поставлена в очередь и ещё не дожата: `compact` работает
  прямо сейчас или завершился с ошибкой.

Обе подсветки — только подсказка: сжать можно всегда, а `F` в меню (или `-f`)
заставит `compact` пройтись по всем файлам заново.

## Журнал и история

`CompactTui.log.txt` лежит рядом с exe: по строке на папку, сколько было и стало,
очищается при каждом запуске. История зелёной подсветки живёт отдельно, в
`%TEMP%\CompactTui\`; её стирает `Shift+G` в меню. Чистильщики временных файлов
Windows тоже могут её удалить — подсветка пропадёт, сжатие останется.

## Сборка из исходников

```bat
build.bat                                  :: собрать CompactTui.exe в корень проекта
start.bat -p D:\data -a                    :: запустить исходник с флагами
python -m unittest discover -s tests -q    :: тесты
```

`build.bat` и `start.bat` берут первое найденное окружение: локальный `python\`,
затем `.venv`, затем `python` из `PATH`. Для запуска из исходников нужны Python 3.8+,
`windows-curses` и `pyinstaller` — `pip install -r requirements.txt`.

## Что именно запускается

```
compact /C /S:. /A /I /EXE:LZX [/F]
```

в отдельном окне, открытом уже внутри сжимаемой папки, — свёрнутом и с полным путём
папки в заголовке, чтобы в списке задач было видно, что сжимается сейчас.
`/C` — сжать, `/S:.` — эта папка со всем вложенным, `/A` — вместе со скрытыми и
системными файлами, `/I` — не останавливаться на занятых, `/EXE:LZX` — алгоритм,
`/F` — принудительно.
